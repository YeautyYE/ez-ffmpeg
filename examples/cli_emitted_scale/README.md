# cli_emitted_scale

Machine-generated by `cli::emit_rust_code` (verified shape V5): the exact
builder equivalent of

```bash
ffmpeg -i in.mp4 -vf scale=1280:-2 -c:v libx264 -crf 23 -preset fast -c:a aac -y scaled.mp4
```

`main.rs` is pinned byte-for-byte against the emitter by a unit test — do not
hand-edit it; regenerate with `cli::emit_rust_code` if the emitter changes.

```bash
cargo run --example cli_emitted_scale
```

Expects an `in.mp4` in the working directory.
