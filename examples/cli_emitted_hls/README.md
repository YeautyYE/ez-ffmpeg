# cli_emitted_hls

Machine-generated by `cli::emit_rust_code` (verified shape V6): the exact
builder equivalent of

```bash
ffmpeg -i in.mp4 -c:v libx264 -crf 23 -c:a aac -f hls -hls_time 6 \
    -hls_playlist_type vod -hls_list_size 0 \
    -hls_segment_filename seg_%03d.ts -y out.m3u8
```

`main.rs` is pinned byte-for-byte against the emitter by a unit test — do not
hand-edit it; regenerate with `cli::emit_rust_code` if the emitter changes.

```bash
cargo run --example cli_emitted_hls
```

Expects an `in.mp4` in the working directory.
