# cli_emitted_clip

Machine-generated by `cli::emit_rust_code` (verified shape V2): the exact
builder equivalent of

```bash
ffmpeg -ss 10 -i in.mp4 -t 4 -c:v libx264 -crf 23 -c:a aac -y clip.mp4
```

`main.rs` is pinned byte-for-byte against the emitter by a unit test — do not
hand-edit it; regenerate with `cli::emit_rust_code` if the emitter changes.

```bash
cargo run --example cli_emitted_clip
```

Expects an `in.mp4` in the working directory.
